# Investment Portfolio Lab

Investment Portfolio Lab is a personal learning project for building practical skills in investments, portfolio management, quantitative finance, and asset pricing.

This repository is intentionally structured as a development lab. I will implement all financial logic myself, including formulas, models, algorithms, tests, and visualizations.

## Scope

- Environment and project scaffolding only
- Structured roadmap from core return/risk statistics to CAPM, APT, and Fama-French factors
- Reproducible Python workflow with notebooks, package layout, tests, and reporting folders

## Getting started

1. Create and activate a Python 3.12+ virtual environment.
2. Install dependencies:
   ```bash
   pip install -e .
   ```
3. Verify tooling:
   ```bash
   python --version
   pytest --version
   jupyter --version
   ```

See `ROADMAP.md` for the learning progression and `DATA_SOURCES.md` for planned datasets.
