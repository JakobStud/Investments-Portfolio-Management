# Planned Data Sources

This project will use the following data sources later in the implementation phase. No datasets are downloaded or processed yet.

## 1) Yahoo Finance / yfinance
- Purpose: historical asset prices for equities, ETFs, and benchmarks
- Access: `yfinance` Python package

## 2) FRED (Federal Reserve Economic Data)
- Purpose: Treasury yields, risk-free rates, and macro/market series
- Access: FRED API and public series endpoints

## 3) Kenneth French Data Library
- Purpose: Fama-French factor datasets (including 3-factor and 5-factor data)
- Access: official data library files
